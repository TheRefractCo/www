Paper is a quiet place for the documents you return to: PDFs, e-books, notes, and the marks you make while reading.

You do not need to set everything up before you begin. Open a document, find your place, and let the rest of the library take shape as you use it.

## Your first five minutes

1. Add a document to your library.
2. Open it in the reader and try the page controls.
3. Mark one sentence with a pen, pencil, or highlighter.
4. Add a note when you want to remember why it mattered.
5. Return to the library and see where the document lives.

> Paper is designed to be useful before it is fully configured. Start with the next page, not a settings checklist.
