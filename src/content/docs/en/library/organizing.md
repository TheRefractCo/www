There is no perfect filing system for a library. The best one is the one that helps you find the next document without making you maintain it all day.

## Start with the documents you revisit

Keep active reading easy to reach. Older documents can stay in the same library until there is a real reason to move them.

## Prefer a few meaningful groups

If your library grows, use broad groups such as “work,” “study,” or “inspiration.” A small number of clear categories is usually easier to remember than a maze of precise labels.

## Make cleanup occasional

Set aside a few minutes when the shelf starts to feel noisy. Remove duplicates, finish one abandoned read, and leave the rest alone until you need it.
